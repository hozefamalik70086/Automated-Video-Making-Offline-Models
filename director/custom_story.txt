# If this file contains any non-comment text, the Director uses THIS as the
# story and does NOT contact the LLM (the AI story writer). Leave this file as
# all-comment lines to use the AI story writer instead.

# FORMAT:
#   Each scene is a block. Separate scenes with a line of exactly three
#   dashes (---) on its own line.
#
#   Inside a block you may optionally use:
#     IMAGE:       <detailed prompt for the image / first frame>
#     VIDEO:       <motion prompt for the video clip>
#     CHARACTERS:  <comma-separated names of every character in the shot>
#     VOICE:       <ambient / narration line to synthesize (edge-tts)>
#     DIALOGUE:    <spoken line, always prefixed "Speaker: line">
#   Plain lines (no prefix) are used for BOTH image and video.
#   When CHARACTERS is present, a bare "Name: line" is treated as dialogue.
#
#   CHARACTERS names are how the pipeline LOCKS identity: the same name in
#   every scene shares one visual descriptor + one voice (see characters.py).
#
#   IMPORTANT: video prompts MUST describe continuous, specific motion from the
#   first frame (a camera move + moving elements). Static/slow wording like
#   "still", "slow", "gentle sway" produces frozen video that fails QC.
#
